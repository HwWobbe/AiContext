# HelloWorldFlask

A tiny Flask app for learning GitHub Copilot workflows and simple web development.

## What it does
- Serves a small home page with a "Hello, World!" message
- Includes a simple API endpoint at `/api/hello`
- Runs locally with Flask's built-in development server

## Run it
From the repo root:

```bash
python docs/HelloWorldFlask/app.py
```

Then open:
- `http://127.0.0.1:5000/`
- `http://127.0.0.1:5000/api/hello`
